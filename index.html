3. Kỹ năng Chuyên môn (Skills)

💻 Front-End Development:

  • Cấu trúc giao diện chuẩn HTML5 Semantic, tạo kiểu với CSS3 (Flexbox, Grid).
  • Lập trình JavaScript: Thao tác DOM, xử lí tác động và gửi về Back-End.
  • Chuyển đổi bản vẽ thiết kế từ Figma Thiết kế giao diện thích ứng với nhiều loại thiết bị.

⚙️ Back-End Development:

  • Xây dựng máy chủ web & dịch vụ RESTful API bằng Node.js & Express.js.
  • xử lí dịnh dạngJSON, cấu hình bảo mật CORS Policy.
  • Thiết lập bảo vệ, chống Spam thư (Rate Limiting) và xử lý trọn vẹn các phương thức GET, POST, DELETE.

🛠️ Công cụ & Quy trình:

  • Quản lý phiên bản mã nguồn: Git & GitHub.
  • Môi trường soạn thảo & gỡ lỗi: Visual Studio Code (VS Code).
  • Phát hành ứng dụng lên Internet: GitHub Pages, Vercel, Render Cloud.
